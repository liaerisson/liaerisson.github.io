Market Simulator

A C++ limit order book and matching engine with price-time priority, trade recording, and performance benchmarks.

C++ CMake 79 Catch2 Tests 1.82M Orders/sec · Single Thread Price-Time Priority

I started this project because I wanted to understand what happens behind a trade and push my C++ beyond coursework. I built a limit order book with price-time priority matching, partial fills, cancellations, and trade history, along with displays for inspecting individual orders and viewing market depth.

The project now has 79 passing Catch2 tests and averaged 1.82 million orders per second in single-threaded Release benchmarks. I built reproducible workloads so I could measure how future changes affect performance.

Next, I want to explore whether concurrency can improve the engine and understand the tradeoffs involved. I’m learning about multithreading and synchronization before implementing and comparing different approaches.

File Ingestor

Java search backend with an inverted index and REST API.

Java JUnit Spring Boot Inverted Index REST API File Processing

I built a Java document search engine that can ingest .txt files from a local directory or accept documents through JSON, build an in-memory inverted index, and rank results for single- and multi-word searches. I started the project because I wanted to understand what actually happens underneath a keyword search while getting more practice with software design, Java collections, file processing, unit testing, and REST APIs.

Paper Analyzer

Analyzes research papers using an AI agent and retrieval-based knowledge base.

Python AWS Bedrock AWS S3 Strands Agents Knowledge Bases Research Synthesis

I started this project in my free time during the final week of my internship, wanting to gain more experience with AI tools by building something useful to me. With my interest in how AI could affect economic decision-making, I chose to build a research agent for analyzing and comparing papers on the subject.

The agent produces summaries, glossaries, and comparisons of methods and findings, with an analysis structure that distinguishes reported results from author interpretation. I continued developing it after the internship, adding browser file uploads, chunking to address latency, and improvements to the interface.
